# Locally releases

Public download and update channel for the **Locally** desktop app.

- **Releases** — signed installers plus the `latest*.yml` files the in-app updater reads.
- **`feeds/`** — small JSON files the app fetches at runtime:
  - `hero.json`: copy for the Settings → About card
  - `model-catalog.json`: the model list in the agent pickers

The app's source code is private. Please don't open issues here.
